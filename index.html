ვინ არ არის თქვენი მიმდევარი

ერთი სკრიპტი, რომელიც აჩვენებს, ვის მიჰყვებით ინსტაგრამზე ცალმხრივად. მუშაობს მხოლოდ თქვენს ბრაუზერში — სერვერი არ არსებობს და მონაცემები არსად იგზავნება.

მხოლოდ წაკითხვის რეჟიმი სკრიპტი ვერაფერს შეცვლის თქვენს ანგარიშზე. მასობრივი გამოწერის მოხსნა განზრახ ამოღებულია.
⚠ გამოიყენეთ საკუთარი რისკით სკრიპტი იყენებს ინსტაგრამის შიდა API-ს, რაც ეწინააღმდეგება მისი მოხმარების წესებს. ანგარიშის დროებითი შეზღუდვის რისკი მცირეა, მაგრამ არსებობს.

★ მიმდევარი

შემდეგ ინსტაგრამზე ერთი დაწკაპუნება საკმარისია.

როგორ გამოვიყენოთ

  1. გახსენით instagram.com და დარწმუნდით, რომ შესული ხართ.
  2. გახსენით კონსოლი — მალსახმობი დამოკიდებულია სისტემაზე.
  3. ჩასვით კოდი და დააჭირეთ Enter-ს.
  4. დააჭირეთ ღილაკს „სკანირების დაწყება“.
ბრაუზერი macOS Windows
Chrome / Edge ⌥ ⌘ J Ctrl Shift J
Firefox ⌥ ⌘ K Ctrl Shift K
Safari ⌥ ⌘ C —
  • macOS-ზე F12 პირდაპირ არ მუშაობს — საჭიროა fn + F12, რადგან ფუნქციურ ღილაკებს ხმა და სიკაშკაშე უჭირავს.
  • Chrome და Edge პირველ ჩასმაზე ითხოვს, რომ ხელით აკრიფოთ allow pasting და დააჭიროთ Enter-ს.
  • Safari-ზე ჯერ Develop მენიუ უნდა ჩაირთოს: Settings → Advanced → „Show features for web developers“.
  • სანიშნეების ზოლი: macOS ⌘ ⇧ B, Windows Ctrl Shift B.

დახურვა: Esc ან ✕ ღილაკი. გვერდი უცვლელი დაბრუნდება. ბუკმარკლეტის გამოყენება ორივე სისტემაზე იდენტურია.
