# მიმდევარი

**ვინ არ არის თქვენი მიმდევარი** — ინსტაგრამის სკანერი, რომელიც აჩვენებს, ვის
მიჰყვებით ცალმხრივად. სრულად ქართულ ენაზე.

მუშაობს მხოლოდ თქვენს ბრაუზერში: სერვერი არ არსებობს და მონაცემები არსად
იგზავნება.

**→ [გახსენით გვერდი](https://19rl96.github.io/mimdevari/)** · [დემო
დიზაინი](https://19rl96.github.io/mimdevari/preview.html)

## ორი გაფრთხილება

**მხოლოდ წაკითხვის რეჟიმი.** სკრიპტი ვერაფერს შეცვლის თქვენს ანგარიშზე.
მასობრივი გამოწერის მოხსნა განზრახ ამოღებულია — ეს მხოლოდ სანახავი ხელსაწყოა.

**გამოიყენეთ საკუთარი რისკით.** სკრიპტი იყენებს ინსტაგრამის შიდა API-ს, რაც
ეწინააღმდეგება მისი მოხმარების წესებს. ანგარიშის დროებითი შეზღუდვის რისკი
მცირეა, მაგრამ არსებობს.

## გამოყენება

### გზა 1 — კონსოლი

1. გახსენით `instagram.com` და დარწმუნდით, რომ შესული ხართ.
2. დააჭირეთ `F12`-ს და აირჩიეთ ჩანართი `Console`.
3. ჩასვით [`mimdevari.js`](./mimdevari.js)-ის სრული შიგთავსი და დააჭირეთ `Enter`-ს.
4. დააჭირეთ ღილაკს „სკანირების დაწყება".

### გზა 2 — ბუკმარკლეტი

გახსენით [გვერდი](https://19rl96.github.io/mimdevari/) და გადმოათრიეთ ღილაკი
სანიშნეების ზოლზე. შემდეგ ინსტაგრამზე ერთი დაწკაპუნება საკმარისია.

დახურვა: `Esc` ან ✕ ღილაკი. გვერდი უცვლელი დაბრუნდება.

## ფუნქციები

- **ცალმხრივი / ორმხრივი** — ვინ არ არის თქვენი მიმდევარი და ვინ არის
- **ფილტრები** — ვერიფიცირებული, დახურული, ფოტოს გარეშე
- **დაცული (★)** — ანგარიშები, რომელთა დამალვაც გსურთ სიიდან
- **ძებნა** — მომხმარებლის სახელით ან სრული სახელით
- **ექსპორტი** — კოპირება, JSON, CSV
- **პაუზა** — სკანირების შეჩერება და გაგრძელება
- ღია და ბნელი თემა, WCAG AA კონტრასტი, `prefers-reduced-motion`

## ბილდი

```bash
node build.mjs
```

აწყობს `mimdevari.min.js`-ს, `bookmarklet.txt`-ს და ბუკმარკლეტს ჩასვამს
`index.html`-ში. საჭიროებს `npx terser`-ს (ავტომატურად ჩამოიტვირთება).

## რა ინახება

„დაცული" ანგარიშები ინახება ბრაუზერის `localStorage`-ში, გასაღებით
`mm_protected`. სხვა არაფერი ინახება.

## შეზღუდვა

სკრიპტი იყენებს ინსტაგრამის შიდა GraphQL მისამართს (`QUERY_HASH` კონსტანტა
ფაილის დასაწყისში), რომელსაც ინსტაგრამი დროდადრო ცვლის. თუ სკანირება ვერ
მოხერხდა და გამოჩნდა შეტყობინება „შესაძლოა ინსტაგრამს შეუცვლია ეს მისამართი" —
სწორედ ეს იქნება მიზეზი. ამ შემთხვევაში `QUERY_HASH` უნდა განახლდეს.
